# Stems

A macOS stem splitter: drop in a track and get vocals, drums, bass and the rest as separate files, split on your Mac.

## Download

Get the latest `Stems-x.y.dmg` from [Releases](https://github.com/andreeeeaaaaas/stems-releases/releases/latest), open it and drag Stems to Applications.

Needs a Mac with Apple silicon and macOS 26.2 or later. Stems checks for updates itself (Stems › Check for Updates…).

This repo holds the signed, notarised builds and the update feed (`appcast.xml`).
